### Insight 3: Circuit Closure and the Deafferentation Paradox
**Section Added:** "Thought Completion and the Closed-Circuit Requirement"

The Problem (3-decade unsolved paradox):
- Deafferented patients: proprioception lost, motor neurons intact
- Standard theory: should degrade precision
- Reality: coordinated movement **abolished**

The Solution:
- Thought is charge that must complete a closed circuit
- Outbound: cortex → motor system → muscles
- Return: muscles → proprioceptors → cortex
- Return path broken → circuit cannot close → thought cannot complete

Why Vision Doesn't Help Enough:
- Ian Waterman uses vision as return path
- But conscious visual processing is slow (~200-500 ms)
- Too slow for reflexes (~50 ms bandwidth)
- Movement succeeds only with conscious attention
- Movement fails instantly when eyes close

**Why This Matters:**
- Not just "feedback is important"
- But "charge circulation requires closure"
- **Consciousness is charge circulation**

### Insight 4: Learning as Emotional Context Remapping
**Section Added:** "Learning as Emotional Context Remapping"

What Learning Is NOT:
- Does not create new motor patterns
- Does not rewire basic neuromuscular circuits
- Does not change the substrate

What Learning IS:
- Training deliberative (slow, conscious) circuits to access reflexive (fast, automatic) substrates
- Extending conscious control without changing controlled patterns
- Remapping which emotional contexts can access a given motor substrate

Examples:

**Fire Breather:**
- Hand withdrawal exists as automatic pain reflex
- Training maps this to skill/intention circuit
- Same motor output, different emotional envelope

**Musician:**
- Finger movements exist in crude form
- Learning: conscious circuit gains access ($\tau \sim 500$ ms)
- Mastery: pattern returns to fast execution ($\tau \sim 50$ ms) but stays consciously controllable
- Result: automatic response that remains voluntarily modulated

**Language:**
- Phoneme production exists in babbling
- Learning: maps to deliberative speech circuit
- Mastery: returns to fast production but consciously accessible

What This Explains:
- Why you can't decide to feel pain (automatic circuit, not volitional)
- Why you can learn to do painful things (practice remaps substrate)
- Why skills become automatic (pattern migrates back to fast circuits)
- Why transfer learning works (same substrate accessible by multiple contexts)
- What mastery is: conscious control of automatic responses
